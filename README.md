# PT booking

Booking-app for privattimer ved Evolution Dance Studio.

## Status

Tidlig fase. Designet (Adobe XD) er ferdig fra et studentprosjekt. Tekniske valg er ikke tatt ennå.

## Komme i gang

1. Åpne en GitHub Issue – start med `Discovery: avklare uklarheter før utvikling starter`.
2. Kjør Claude Code i repoet (`claude`) og be den jobbe med discovery-issuen.
3. Når intervjuet er fullført, oppdaterer agenten `docs/DECISIONS.md` og lager epic-issues for resten av arbeidet.

## Struktur

- [`docs/CONTEXT.md`](docs/CONTEXT.md) – bakgrunn, problembeskrivelse, hva vi vet
